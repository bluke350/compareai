Setup

Three steps, one file

Every outbound tool link carries a data-aff attribute. The site resolves it from the config at load time. You never touch the HTML.

Apply to a program

Pick one from the directory above and use its free apply link. Approval is usually same-day for Writesonic and Rytr, a few days for Jasper and Surfer. You need a live page and a real email.

Copy your tracking URL

Your dashboard issues a unique link — something like https://surfer.ai/?fp_ref=abc123. Do not shorten or edit it beyond adding sub-IDs where the network supports them.

Paste it into the config

Open assets/js/affiliates.js, find the matching slug and paste the URL between the quotes. Save, reload, and the button points at your link. The monetization panel above updates to “Link live”.

// assets/js/affiliates.js
window.AFFILIATE_LINKS = {
  jasper:     "https://jasper.ai/?fpr=YOURID",
  writesonic: "https://affiliates.writesonic.com/...",
  surfer:     "https://surfer.ai/?fp_ref=YOURID",
  elevenlabs: "https://elevenlabs.io/?affiliate_id=YOURID",
  synthesia:  "https://www.synthesia.io/?via=YOURID",

  // leave the rest empty — those buttons fall back
  // to the vendor site, so nothing ever dead-ends
  copilot:    "",
  cursor:     ""
};

Empty entries are safe: the link resolves to the vendor's own site, tagged rel="sponsored noopener". No broken buttons, no fake links.

Publish

Live for $0 on GitHub + Cloudflare Pages

No build step, no framework, no server. Push the folder to GitHub, connect the repo in Cloudflare, done. You get a free *.pages.dev URL and free HTTPS.

Option A — Git integration

Best for ongoing edits

  1. Create a free GitHub repo and push this folder.
  2. Cloudflare dashboard → Workers & Pages → Create → Pages → Connect to Git.
  3. Pick the repo. Framework preset: None. Build command: leave empty. Build output directory: /.
  4. Save and deploy. Every future push to main redeploys automatically.
git init
git add .
git commit -m "CompareAI comparison site"
# create the repo on github.com, then:
git remote add origin https://github.com/YOU/compareai.git
git branch -M main
git push -u origin main
Option B — Wrangler CLI

Best for a one-off publish

Cloudflare's CLI deploys the folder directly. You still need a free Cloudflare account; no card is required for the Pages free plan.

npm install -g wrangler
wrangler login

wrangler pages project create compareai \
  --production-branch main

wrangler pages deploy . \
  --project-name compareai

Free plan limits: 500 builds per month, unlimited requests and bandwidth. That is more than this site will ever need.

Optional cost: a custom domain. Everything else — repo, build, host, HTTPS, affiliate accounts — is free.

Why not GitHub Pages? It works too and is equally free. Cloudflare Pages gives you unlimited bandwidth, edge caching and the _headers / _redirects files included in this repo. Both are fine; Cloudflare is the better default if traffic grows.
Stay legal

Four rules that keep the money

Disclosure

Say it before the click

The FTC requires a clear, conspicuous disclosure near affiliate links — not buried in the footer. This site puts one on every comparison page. Keep it there.

No income claims

Sell the tool, not a dream

Never promise readers they will earn a certain amount. Programs terminate affiliates who make income claims, and it is the fastest way to lose an audience.

Program rules

No brand bidding

Most programs forbid bidding on the vendor's brand in paid search and forbid coupon-injection extensions. Read the terms once; it takes ten minutes and prevents a ban.

Privacy

First-party counts only

This site stores a theme choice and a compare list in your browser. Outbound affiliate clicks are counted in aggregate on Cloudflare — no cookies, no IP addresses, no third-party analytics, no consent banner. Vendors set their own cookies after the click.

FAQ

Money questions

Do any of these programs charge a joining fee?

No. Every program listed here is free to apply to and free to participate in. Nobody asks for a card. If a “program” asks you to pay to join, it is not an affiliate program — walk away.

Do I need a minimum amount of traffic?

Most of these do not publish a minimum. Semrush asks for at least 1,000 unique monthly visitors for content publishers, and Jasper reviews your site manually. Writesonic and Rytr approve quickly with no stated minimum. Start by applying to one, not all thirteen.

How much can this realistically earn?

At 10 referrals a month to ElevenLabs' 22% program, the model shows about $581 a year before churn — enough to cover a few subscriptions, not a salary. The realistic path to meaningful income is ranking for buyer-intent searches, which takes months of content. The calculator is arithmetic, not a forecast.

What if a program rejects me?

Apply to another. Approval is usually about having a live, relevant page and a real audience. Rejections are common for brand-new sites with no content. Publish the comparison pages first, then apply.

Do I have to keep the no-program tools on the site?

You can remove them, but you should not. Pages that only list paying tools read as adverts and convert worse. Midjourney, Copilot and Cursor are the tools readers search for — including them is why the paying recommendations get believed.
